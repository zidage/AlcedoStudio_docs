# Alcedo Studio tutorials

These tutorials use **v0.3.3** as their operating baseline and cover changes from v0.2.x through v0.3.3. Projects store photo references, edits and named versions; editing leaves the source photos unchanged.

## Start here

1. [Install the application](./getting-started/installation.md).
2. [Find your way around the interface](./getting-started/interface-overview.md).
3. [Import, edit and export your first photo](./getting-started/first-edit.md).

## Upgrading

Read the [upgrade guide](./releases/upgrade-guide.md) first. **v0.3.0 and later cannot open or automatically migrate projects from v0.2.9 or earlier.** LUT distribution, crop behavior, color wheels and diffusion also changed.

The release archive retains complete feature, improvement, performance and fix notes for all fourteen versions, linked to current tutorials. See the [source map](./developer/tutorial-source-map.md) for the production QML entry points and verification scope.
