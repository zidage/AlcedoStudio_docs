# Documentation Overview

Alcedo Studio is an open-source RAW image processing and digital asset management (DAM) project for photography workflows, offering a high-performance RAW editing pipeline as well as AI-powered content label generation and semantic search.

## Current scope

- [Quick start](./getting-started/installation.md): installation, understanding the interface, and editing your first image.
- [Edit History and Versions (UI)](./getting-started/edit-history-and-versions): the Versions / Edit History panels, plus Paste and Merge.
- [AI features](./ai/overview.md): local model download and activation, API provider configuration, content labels, image rating, and semantic / fuzzy search.
- [Edit History and Versions (Mini-Git)](./developer/edit-history-architecture): the commit graph, recovery log (WAL), and materialization.
