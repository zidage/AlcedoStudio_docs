核心设计理念

Alcedo Studio 采用以 DuckDB 为底座的非破坏性元数据数据库，将原始照片与修改操作严格分离；图像处理管线基于物理场景线性空间（ACES / OpenDRT），搭配 Git 式分支版本管理与原生 GPU 硬件加速，兼顾摄影暗房的严谨色彩科学与流畅交互。
