# 端侧 AI 与智能分析概览

Alcedo Studio 针对专业数字暗房的现实需求，确立了 **端侧优先（On-Device First）** 与 **自动化协同（CLI Automation）** 的智能架构。在彻底消除隐私泄露风险的同时，让 AI 真正赋能摄影资产的整理与调色。

---

## 核心设计理念：隐私、极速与免配置

在传统修图工具中，让用户在图形界面中手动填写第三方 API Key、配置反向代理与复杂端点是一套原始且繁琐的体验。随着现代大模型能力与自动化工具的演进，Alcedo Studio 将智能能力解耦为两条高效路径：

```text
                                  ┌──▶ [ 1. 本地端侧 AI (Local CLIP / ONNX) ]
                                  │      - 100% 离线计算，0 字节图像外发，零 API 费用
[ Alcedo Studio 智能中枢 ] ──────┤      - 毫米级自动内容打标与自然语言语义检索
                                  │
                                  └──▶ [ 2. 自动化协同中枢 (alcedo-cli) ]
                                         - 免去 GUI 中繁琐的人工 API 接入与维护
                                         - 外部智能体直接通过本地 RPC 协同调色与批处理
```

### 1. 绝对的本地隐私保护（100% Private）
摄影师的原始 RAW 素材往往包含商业机密、私人客户肖像或敏感地理位置。Alcedo Studio 的视觉内容识别模型完全运行在本地（CPU / GPU 硬件加速），无论是生成内容标签还是执行跨语言自然语义检索，照片与特征向量**绝不离开本地磁盘**。

### 2. 本地实时极速响应
本地模型经过针对性的轻量化微调，单张照片推理仅需毫秒级，在数百张照片导入时即可同步完成标签归纳，免除等待云端网络往返延迟的痛苦。

### 3. 告别繁琐的手动 API 配置
我们认为在修图软件中让用户反复申请、绑定 API 密钥并管理各种供应商账户既繁琐又与暗房心智相悖。借助强大的 `alcedo-cli`，外部 AI 智能体可直接在命令行或后台脚本中驱动 Alcedo Studio 协同工作，带来真正的全自动化体验。

## 核心功能导航

1. **[本地模型管理与部署](./model-management.md)**  
   选择官方源或国内镜像源（如 HF 镜像、Sufy CDN），一键下载、校验并激活本地轻量化视觉模型。
2. **[AI 自动内容标签生成](./label-generation.md)**  
   在导入照片时自动打标，或在相册中一键批量重打标签，实现照片按主体属性快速归类。
3. **[AI 自然语言与多维搜索](./search.md)**  
   无需事先手动整理标签，直接输入自然语言（如“海边红色跑车”、“雪景木屋”）快速定位目标照片。
4. **[智能体交互与 CLI 命令行](../automation/cli.md)**  
   了解如何通过 `alcedo-cli` 让 AI 智能体直接辅助调整曝光、切换风格版本并实现无头流水线批量修图。
