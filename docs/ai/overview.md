# 本地 AI 与自动化概览

Alcedo Studio 使用本地视觉模型生成照片标签和支持自然语言搜索。外部脚本或 AI 智能体可以通过 `alcedo-cli` 操作项目和编辑照片。

---

## 本地模型与命令行

本地模型与命令行工具分别用于内容识别和自动化操作：

```text
                                  ┌──▶ [ 1. 本地端侧 AI (Local CLIP / ONNX) ]
                                  │      - 在本地生成内容标签和进行自然语言搜索
[ Alcedo Studio ] ───────────────┤
                                  │
                                  └──▶ [ 2. 命令行工具 (alcedo-cli) ]
                                         - 外部脚本或智能体通过本地 RPC 编辑和批处理
```

### 1. 本地内容识别
下载并激活模型后，标签生成和自然语言搜索使用本地模型进行推理。

### 2. 命令行自动化
外部脚本和 AI 智能体可以通过 `alcedo-cli` 连接应用窗口，或启动无头会话执行批处理。外部智能体的配置由其所使用的工具决定。

## 核心功能导航

1. **[本地模型管理与部署](./model-management.md)**  
   选择下载源，下载、校验并激活本地视觉模型。
2. **[AI 自动内容标签生成](./label-generation.md)**  
   在导入照片时生成标签，或为图库中的照片批量重新生成标签。
3. **[AI 自然语言与多维搜索](./search.md)**  
   输入自然语言（如“海边红色跑车”、“雪景木屋”）搜索照片，无需事先手动添加标签。
4. **[智能体交互与 CLI 命令行](../automation/cli.md)**  
   了解如何通过 `alcedo-cli` 让 AI 智能体直接辅助调整曝光、切换风格版本并实现无头流水线批量修图。
