AI 搜索与模糊搜索

Alcedo Studio 的全局搜索入口位于相册左侧工具区的 Search（搜索）。当前搜索对话框支持按文件信息查找、按自然语言理解图像内容，以及直接定位某一张照片。

语义路线使用 Local Content Recognition（本地内容识别） 中已激活的本地 CLIP 模型；它不使用 API 供应商的描述或评分配置。API 供应商生成的图像描述如果已经保存，也可以作为普通搜索字段被检索。

打开搜索​

点击左侧 Search（搜索），打开搜索对话框。搜索框占位提示为 Search photos, cameras, lenses, dates...（搜索照片、相机、镜头、日期...）。输入内容后，下方会先显示预览结果；按回车或点击 Search（搜索） 才会正式应用搜索。

右上方的 Search settings ▾（搜索设置 ▾） 会打开 Search conditions（搜索条件） 面板。面板中的每个选项都已经支持中文翻译：

英文选项中文界面作用
Filename文件名在文件名中查找关键词
EXIF infoEXIF 信息在相机、镜头、日期等 EXIF 元数据中查找
AI descriptionAI 描述文本在已经保存的 AI 描述文本中查找
AI tagsAI 标签在本地模型生成的标签中查找
Natural language search自然语言搜索用本地 CLIP 模型按图像含义查找

前四个字段筛选默认开启，可以单独关闭。Natural language search（自然语言搜索） 是单独的开关，打开后会与上方四个字段筛选互斥；界面会禁用这些复选框，避免两种搜索方式同时生效。这个开关会记住上次选择。

模糊搜索：按文件信息查找​

关闭 Natural language search（自然语言搜索） 时，输入关键词会按当前勾选的字段进行模糊匹配。适合查找：

  • 相机型号、镜头型号或拍摄日期；
  • 文件名中的词语；
  • 本地 AI 生成的标签；
  • 已保存的 AI 描述文本。

搜索结果会显示文件名、相机型号、拍摄日期，以及评分或镜头信息。点击 Search（搜索） 后，搜索条件会应用到相册，右侧检查器会显示 SEARCH FILTER（搜索筛选），可以点击其中的 x 清除。

自然语言搜索：按图像含义查找​

打开 Natural language search（自然语言搜索） 后，软件会先判断输入内容是否适合自然语言路线：

  • 被识别为自然语言查询时，按回车或点击 Search（搜索） 后才会真正执行自然语言搜索。
  • 不符合自然语言条件的查询仍会按普通模糊搜索处理。
  • 预览阶段可能显示 Press Enter or click Search for natural language search（按回车或点击搜索按钮以执行自然语言搜索）。

例如可以输入 a dog on the beach 或 夜景人像，按画面内容查找照片，而不需要文件名或元数据中包含这些词。自然语言搜索在本机使用已激活的 CLIP 模型，不会因为这项功能把照片发送给 API 供应商。

如果本地模型不可用，界面会显示：

  • Query is too long for natural language search（自然语言搜索的查询过长）：缩短输入内容后重试。
  • Natural language search is not available yet（自然语言搜索暂不可用）：先在 Local Content Recognition（本地内容识别） 中下载并激活模型。

如果你只想按文件名、EXIF 信息、AI 描述文本或 AI 标签查找，请关闭自然语言搜索开关。

建议与结果​

没有输入内容时，列表标题显示 Suggestion（建议）。软件会按相机、日期、镜头等类别提供建议；点击建议项会直接应用普通模糊搜索。如果没有建议，会显示 No recent suggestions（没有最近的建议）。

输入内容后，列表标题变为 Results（结果），旁边显示匹配数量，例如：

  • %1 matches（%1 个匹配项）；
  • 0 of %1 matches（0/%1 个匹配项）；
  • %1-%2 of %3 matches（匹配项 %1-%2，共 %3 项）。

如果当前相册已经应用其他搜索条件，标题旁边会显示 Active: %1（当前：%1）。

翻页与加载状态​

结果较多时，列表支持前后翻页：

  • 到达列表上方时，可以点击 Load previous（加载上一项）。
  • 到达列表下方时，可以点击 Load more（加载更多）。
  • 滚动到接近边缘时，列表也会自动加载上一页或更多结果。

搜索正在执行时显示加载指示器。没有结果时显示 No matches（无匹配项）；如果是自然语言路线，错误提示会显示在同一个位置。

每条结果还可能显示 Rating %1/5（评分 %1/5）。点击结果行会执行精确匹配，直接定位到该照片；如果源文件不可用，界面会提示 Source file is unavailable（源文件不可用），预览图像加载失败时会提示 Preview image failed to load（预览图像加载失败）。

三种查找方式​

  • 模糊搜索：使用 Filename（文件名）、EXIF info（EXIF 信息）、AI description（AI 描述文本） 和 AI tags（AI 标签） 查找，适合知道文件信息或已有标签的情况。
  • 自然语言搜索：打开 Natural language search（自然语言搜索），使用本地 CLIP 模型按画面含义查找，适合描述“海边日落”“夜景人像”等内容。
  • 精确匹配：点击某一条搜索结果，直接定位对应照片。

本地模型未激活时，自然语言搜索不可用，但模糊搜索与精确匹配仍可正常使用。模型下载和激活步骤见本地 AI 模型管理。
