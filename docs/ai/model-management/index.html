本地 AI 模型管理

本页介绍 Settings（设置）→ Local Content Recognition（本地内容识别） 中的本地视觉模型。下载并激活模型后，它可以用于导入时的内容标签生成、标签筛选和语义搜索；图像推理在本机完成。

如果你要配置 API 供应商，为照片生成描述、评分和评分理由，请改看 API 供应商配置。

打开本地 AI 设置​

点击工具栏的 Settings（设置），在左侧选择 Local Content Recognition（本地内容识别）；或在导入图像时出现 Set up an AI model to analyze images（设置用于分析图像的 AI 模型） 提示后点击 Set up model（设置模型），软件会直接跳转到该分类。

页面包含三个主要区块：

  • AI content recognition（AI 内容识别）：查看当前相册的标签统计，进入生成或重新生成流程。
  • Model（模型）：选择、下载和激活本地模型。
  • Import（导入）：设置导入新图像时是否自动生成标签。

选择模型​

在 Model（模型） 区块顶部的下拉框中选择模型。列表中的模型在体积、精度和语言支持上有所不同；选中后，状态卡会显示显示名与总大小。如果不确定选哪个，先使用默认项即可，后续可以切换并重新下载。

设置下载目录​

Download directory（下载目录） 显示模型文件的存放路径。点击右侧的文件夹图标，在 Select Model Download Folder（选择模型下载文件夹） 中选择目录。模型文件较大，建议选择空间充足、便于长期保留的位置，不要随意删除该目录下的文件。

选择镜像源​

Source（来源） 下拉框提供四个选项：

  • HF Mirror（HF 镜像）：面向国内网络环境的 Hugging Face 镜像源，访问官方站点较慢或不稳定时优先使用。
  • Hugging Face（Hugging Face）：官方源，网络条件良好时使用，文件最全、更新最及时。
  • Sufy CDN（Sufy CDN）：CDN 分发的镜像源，可作为前两者的备选。
  • Custom（自定义）：自定义下载地址。选择后会出现输入框，填入完整的下载根地址，例如 https://example.com。

选择建议：能直连官方源且速度尚可就使用 Hugging Face；国内访问困难时使用 HF Mirror；如果两者都慢，再尝试 Sufy CDN 或自定义地址。下载失败或卡住时，换源后重新 Download 通常是最直接的排查方式。

下载与激活​

设置好模型、目录和来源后：

  1. 点击 Check（检查） 刷新当前模型的本地状态；未下载时会显示 Not downloaded（未下载）。
  2. 点击 Download（下载） 开始下载。状态卡会显示百分比、已下载 / 总字节数、当前文件名、下载速度和预计剩余时间。下载过程中按钮变为 Cancel（取消）。
  3. 下载完成后，状态卡显示 Activate to generate labels（激活以生成标签），表示文件已就位但尚未载入运行时。
  4. 点击 Activate（激活）。完成后状态卡显示绿色的 Active（已激活），此时可以生成标签和使用语义搜索。

模型状态卡​

状态卡是模型状态的主要依据：

  • 红色 / Not downloaded（未下载）：本地没有完整模型文件。
  • 强调色 / Downloading %1%（下载中 %1%） 或 Activating…（激活中…）：下载或激活进行中。
  • 灰色 / Activate to generate labels（激活以生成标签）：文件已下载，但还没有激活。
  • 绿色 / Active（已激活）：本地模型已准备好。

空闲时，状态卡下方还会显示控制器返回的信息，例如错误、安装路径或当前运行时状态。

其他操作​

  • Check（检查）：重新读取所选模型的本地状态。
  • Download（下载） / Cancel（取消）：开始或中断下载。
  • Delete（删除）：删除该模型的本地文件，状态回到 Not downloaded（未下载）。
  • Activate（激活）：载入已下载的模型。

导入时的标签偏好​

Import（导入） 区块中的标签生成选项控制导入新图像时的行为：

  • Always（总是生成）：每次导入都生成，不再询问。
  • Always Ask（总是询问）：每次导入都弹出 Use AI to analyze image content?（使用 AI 分析图像内容？）。
  • Always Skip（总是跳过）：导入时不生成标签，也不弹出模型引导提示。

具体的导入对话框和手动生成流程见 AI 标签生成。

排查​

  • 下载失败或长时间无进度：更换 Source（来源） 后重新 Download（下载）；自定义源请确认地址可达且目录结构与官方一致。
  • 下载完成但 Activate（激活） 失败：检查目录是否完整、磁盘空间是否充足，必要时 Delete（删除） 后重新下载。
  • 已显示 Active（已激活） 但标签生成仍不可用：确认当前项目已打开，并在本地 AI 分类中点击 Check（检查） 刷新状态。
  • 语义搜索仍不可用：确认本地模型是 Active（已激活）；API 供应商配置不会替代本地语义搜索模型。
