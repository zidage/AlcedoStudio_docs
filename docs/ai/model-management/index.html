本地 AI 模型管理与激活

Alcedo Studio 的离线内容识别与自然语言语义搜索基于 CLIP（Contrastive Language-Image Pre-training） 视觉模型，由内置的 ONNX Runtime 高性能推理引擎驱动。本页介绍如何下载、管理并激活本地模型。

本地模型运作原理​

本地视觉模型将导入的图像编码为高维向量（Embeddings）：

  • 自动内容标签：将图像特征向量与预置的数千个摄影语义标签库进行余弦相似度匹配，毫秒级筛选出最贴切的主题标签。
  • 自然语言语义检索：当你在搜索框输入“暴风雨中的灯塔”时，文本编码器将查询转换为文本特征向量，并在本地图库数据库中进行极速向量相似度检索。
  • 100% 数据隐私安全：所有的神经网络前向推理均在你的计算机本地（CPU / GPU）完成，不产生任何网络外发流量。

配置模型存储与下载源​

点击顶部菜单栏 设置（Settings），在左侧选择 本地内容识别（Local Content Recognition）：

本地模型管理控制台：选择模型、下载源与激活状态

1. 选择视觉模型（Model）​

在模型下拉框中挑选适合你机器配置的预训练模型：

  • 默认推荐模型：在模型体积（约几百兆）与推理速度之间取得完美平衡，适合绝大部分现代电脑。
  • 高精模型（如有）：具备更广泛的概念词汇表与更细腻的场景理解能力，适合高配置工作站。

2. 指定下载目录（Download Directory）​

点击文件夹图标选择模型权重的保存路径。建议存放在剩余空间充足的固态硬盘分区中。

3. 选择镜像加速源（Source）​

根据你所处的网络环境选择最顺畅的下载节点：

  • HF 镜像（HF Mirror）：针对国内网络深度优化的 Hugging Face 镜像，访问速度快且稳定，国内用户首选。
  • Hugging Face 官方源：海外用户或直连环境首选，保障文件最新。
  • Sufy CDN：备选的高速全球 CDN 分发节点。
  • 自定义（Custom）：企业内网或私有化部署时，可填入内部模型的直链镜像地址。

下载与激活流程​

  1. 检查状态：点击 检查（Check）。如果本地尚未存在模型文件，状态卡显示红色的 未下载（Not downloaded）。
  2. 启动下载：点击 下载（Download）。状态卡将显示下载百分比、已下载字节数与预计剩余时间。如遇网络波动，可点击 取消（Cancel），换源后重新点击下载。
  3. 激活模型（Activate）：下载完成后，状态卡会显示灰色的 激活以生成标签（Activate to generate labels）。点击 激活（Activate） 按钮，系统将模型载入 ONNX Runtime 内存中。
  4. 就绪状态：当状态卡变为清爽的绿色 已激活（Active） 时，表示本地 AI 引擎已完全就绪！

导入偏好设置（Import Preference）​

在 导入（Import） 区块中，你可以设定新照片导入图库时的自动化行为：

  • 总是询问（Always Ask，默认）：每次导入时弹出轻量提示框，由你决定本次是否执行 AI 识别。
  • 总是生成（Always）：所有新导入的照片自动进入后台识别流水线并生成标签。
  • 总是跳过（Always Skip）：导入时不触发任何 AI 计算，保留手动打标入口。

模型激活完成后，请继续阅读 AI 自动标签生成 与 AI 自然语言与多维搜索。
