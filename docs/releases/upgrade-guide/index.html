版本演进与升级指南

Alcedo Studio 从初期的跨平台探索逐步演进为成熟的专业级数字暗房与数字资产管理系统。本文梳理了关键版本的核心架构演进以及升级时的重要注意事项。

升级核心注意事项​

在跨大版本升级前，请重点了解以下架构与工作流变化：

变更项涉及版本升级与操作指引
项目格式升级（不兼容 v0.2.x）v0.3.0 起v0.3.0 全面重构了底层节点流水线与 DuckDB 项目格式。无法直接打开 v0.2.9 及更早版本的项目。建议保留旧版本软件以导出旧工程的成品，或在 v0.3.x 中新建项目重新导入源照片。
节点流水线与图层重构v0.3.0 起引入多节点串联、图层式蒙版组与 CAT02 创意白平衡。原有的旧式合并操作已平滑演进为更安全的 选择性参数复制/粘贴。
LUT 分发与编码重构v0.3.1 起官方胶片 LUT 包转为按需下载分发。升级后请进入 设置 → LUT 下载官方包；自定义 LUT 需在面板中正确指定输入/输出色彩空间编码。
工业级全能导出预设v0.3.3 起全能导出预设取代了旧版仅包含文件名的预设，提供针对 Web、社交媒体、印刷打样的完整输出配置，并默认针对网络分享启用 GPS 隐私剥除。

关键版本演进历程​

v0.3.x 时代：节点流水线、色彩科学与智能自动化​

  • v0.3.3：引入 alcedo-cli 命令行中枢与 AI 智能体协同控制；推出全功能导出预设与 GPS 隐私过滤；强化 Ultra HDR 增益图输出与后台批处理队列。
  • v0.3.2：支持位图输入色彩空间自动识别（JPEG、PNG、TIFF、OpenEXR）；支持 3D LUT 输入/输出色彩空间编码关联记忆；引入顶部常驻任务指示灯。
  • v0.3.1：官方胶片 LUT 在线包管理器；新增 A/B 视觉对比系统；新增全图胶片柔光（Diffusion）；图库支持字段多维排序与动态分组。
  • v0.3.0：里程碑版本。全新 .alcd 项目架构；推出节点式色彩分级管线与径向/渐变蒙版组；引入基于 CAT02 矩阵的创意外观白平衡与中灰对比度算法。

v0.2.x 时代：单窗口交互与跨平台底座​

  • v0.2.9：数字签名在线更新体系；导出检查器集成；支持胶片带无缝浏览。
  • v0.2.8：全 QML 单窗口现代化工作区架构；引入 GPU 神经网络去马赛克；引入事务恢复日志与文件夹递归扫描导入。
  • v0.2.7：云端 API 多模态大模型对接；引入 5 档严苛程度摄影打分与评图理由；支持 OpenAI Codex OAuth 免密登录。
  • v0.2.6：新增胶片颗粒与光学光晕合成；引入端侧离线视觉模型，实现毫秒级自动内容打标与自然语言语义检索；原生支持 Nikon HE/HE* 压缩解码。
  • v0.2.4–v0.2.5：引入 DuckDB 驱动的 Sleeve 资产管理引擎；新增 OpenCL 加速后端；支持局部明暗双边滤波与 8 色选择性色彩调整。
  • v0.2.0–v0.2.3：确立 Alcedo Studio 品牌；搭建 macOS Metal 3 统一内存加速与 Windows CUDA 硬件管线；确立 ACES 场景线性色彩管理规范。

查阅各版本的完整功能增补、性能优化与 Bug 修复细节，请点击侧栏的 逐版更新记录。
