v0.3.1

本页保留主仓库的完整版本说明，包括功能、改进、性能与修复。原始记录。历史说明中的旧入口或限制仅适用于当时版本；当前操作以 v0.3.3 教程为准。

对应教程​

  • editing/lut-library
  • editing/comparison
  • library/import-and-organize

完整更新说明​

升级前须知​

  • 安装包不再包含 LUT 文件。请在“设置 > LUT”中下载官方 LUT 包。项目会保留所选的 LUT； 如果 LUT 文件缺失，照片会在不应用该 LUT 的情况下渲染，文件恢复后自动重新生效。
  • 裁剪与旋转改用新的工作方式。带有旋转裁剪的旧照片升级后外观可能有所变化。
  • Gamma 色轮及其主滑块的方向已更正，Gain 主滑块现在会生效。使用过这些调整的旧照片 升级后外观可能有所变化。

新功能​

  • LUT 浏览器：编辑器工具栏新增 LUT 页面，以网格或列表显示 LUT 库。可按类别、来源、 胶片品牌、印放胶片和收藏筛选，搜索可容忍少量拼写错误。点击 LUT 即应用到所选调色 节点，再次点击即移除。新增强度设置（0-100%），可单独控制每个 LUT。
  • LUT 库：会识别嵌套文件夹中的 LUT，也可以导入自己的 LUT。在“设置 > LUT”中可以选择、 打开、刷新和移动 LUT 库文件夹，并可下载、更新或修复每个官方 LUT 包。LUT 包安装前会 校验签名。
  • 柔焦滤镜：模拟黑柔焦滤镜效果，让明亮光源产生柔和光晕，同时保持中间调细节清晰。 它位于新的“后期处理”页面，与清晰度、锐化、胶片颗粒和光晕放在一起。支持 CUDA、 OpenCL 和 Metal。
  • 对比：可从视图或版本面板对比修改前后，或对比两个版本。可并排显示两张完整图片，或 使用可拖动的分隔线，支持左右或上下布局，并可交换两侧。两侧均使用当前的去马赛克、 高光和镜头设置。
  • 图库排序与分组：相册检查器的每个字段都提供升序、降序和分组操作。分组以可折叠、 可展开的区块显示。新增“导入时间”区块，可按导入日期筛选照片。
  • 欢迎界面：最近的项目会以预览形式显示，包括前几张照片组成的封面、照片数量、已编辑 照片数量和拍摄日期范围。点击其他最近项目即可预览。仅预览而未进入的项目不会被保存。
  • 评分：通过右键菜单设置的评分现在会应用到所有选中的照片。评分在后台保存，任务栏会 显示进度。

编辑器与图库​

  • 复制调整现在可以复制 RAW 解码、白平衡、镜头校正以及裁剪与旋转。粘贴到多张照片时 在后台运行并显示进度。粘贴到当前打开的照片时，新版本会立即出现在版本面板中。粘贴 操作已从历史记录移到版本面板。
  • 裁剪：裁剪框即为输出图像，因此裁剪后再旋转会旋转裁剪后的图像。裁剪框始终位于照片 范围内，旋转裁剪不会出现空白角。每次裁剪修改都是一个历史步骤，比例设置随照片保存。
  • 打开 RAW 解码、显示变换或后期处理面板时，在浏览器中选择的 LUT 会应用到上一次选中的 调色节点，浏览器会显示该节点名称。
  • 调整面板顺序改为 RAW 解码、几何、影调、色彩、LUT、显示变换、后期处理。蒙版和对比 仅在使用时显示。

性能​

  • RAW 导入大幅提速。在 639 张 RAW 照片的测试中，导入耗时从 31.6 秒降到 1.1 秒，峰值 内存从 485 MB 降到 149 MB。
  • 项目打开更快。在 641 张照片的测试中，打开耗时从约 0.7 秒降到约 0.12 秒。解压打包 项目时会显示加载指示。
  • 打开项目后首批缩略图出现得更快。每个项目在磁盘缓存中保留自己的缩略图，不再被其他 项目挤掉。
  • 缩略图和导出使用独立的 GPU 资源。缩略图不再拖慢编辑器预览；拖动滑块时导出会使用 已保存的值。

修复​

  • 点击裁剪可能会删除照片的全部编辑历史；裁剪可能未记入历史，导致撤销无法回到完整 画面。
  • 粘贴后 LUT 面板会显示粘贴的值。在胶片带切换照片后，LUT 修改会立即生效。在粘贴对话框 中点击取消不再清除已复制的调整。
  • 应用有时无法关闭，或在关闭后报错退出。
  • Windows：退出后临时项目文件不再残留在临时文件夹中。
  • 应用默认不再写入预览性能日志文件。
