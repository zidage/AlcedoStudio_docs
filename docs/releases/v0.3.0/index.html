v0.3.0

本页保留主仓库的完整版本说明，包括功能、改进、性能与修复。原始记录。历史说明中的旧入口或限制仅适用于当时版本；当前操作以 v0.3.3 教程为准。

对应教程​

  • editing/nodes-and-masks
  • editing/raw-and-geometry
  • releases/upgrade-guide

完整更新说明​

升级前须知​

  • Alcedo Studio 0.3.0 无法打开 0.2.9 及更早版本的项目，也不会转换这些项目。如需使用 旧项目，请保留 0.2.9，或先在 0.2.9 中导出图片。原始照片文件不受影响。
  • 导入只接受相机 RAW 文件。JPEG、TIFF、PNG、HEIC 等非 RAW 文件会被拒绝。

新功能​

  • 节点面板：在“显影”与显示变换之间用节点图串联多个调色节点。可以添加、重命名、删除 和连接调色节点。撤销、重做和版本都会保留节点图。
  • 径向蒙版与渐变蒙版：直接在照片上绘制蒙版，并用控制柄调整。每个调色节点有自己的 蒙版，可设置反相、不透明度和羽化。
  • 图层（蒙版组）面板：每个调色节点显示为一个图层，并附带蒙版缩略图。可以添加和删除 图层，拖动图层即可调整调色顺序。可以锁定调色节点防止被删除，第一个调色节点默认锁定。
  • 选中节点后，调整面板即编辑该节点。面板上方的标题栏显示节点名称、焦距、光圈、快门 速度和 ISO。
  • 外观面板新增“调色白平衡”，可为单个调色节点或蒙版设置色温和色调。相机白平衡现在 位于 RAW 解码面板。
  • 对比度现在围绕中灰调整明度：保持色相，中灰不变。新图片的默认对比度为 +15。
  • 设置中新增“键盘”页面，可修改每个快捷键。页面会提示冲突，并可将每个快捷键恢复为 默认值。修改立即生效。
  • 带嵌入颜色配置的 DNG 文件现在会应用 HueSatMap、LookTable 等配置数据，颜色显示 正确。
  • 相册检查器新增“活跃度”视图，显示每个拍摄日期的照片数量。点击某一天即可按该日期 筛选相册。

编辑器与图库​

  • 复制调整：先选择来源版本，再为每个调色节点和显示变换选择要复制的项目。粘贴会创建 新版本。粘贴不会复制 RAW 解码、镜头以及裁剪与旋转设置。历史记录中的“合并”操作 已移除。
  • 镜头校正现在位于 RAW 解码面板。可按品牌和型号搜索镜头。自动识别会根据照片元数据 选择镜头。
  • 搜索现在可以查找拍摄日期（6月7日、June 7、2026-06-07）、文件类型（raw、dng、 jpg）和拍摄参数（iso800、f/2.8、35mm）。多个搜索词按“且”组合。单独输入数字不再 匹配 ISO，请输入 iso800。
  • 清晰度、锐化、胶片颗粒和光晕现在在显示变换之后对整张图片只应用一次。预览与全尺寸 结果一致。
  • 编辑器工具栏的每个图标下方显示文字标签。设置新增“语言 / 主题”页面和“默认行为” 页面。“关于”页面提供文档和 GitHub 链接。
  • 在小屏幕上，较长的标签会换行显示，不再被截断。
  • 裁剪和蒙版控制柄会显示旋转、移动和缩放光标。
  • 所有新功能均提供简体中文界面。

性能​

  • 全新的 GPU 渲染引擎在 Windows 上使用 CUDA 和 OpenCL，在 macOS 上使用 Metal。 修改只重新渲染受影响的步骤。缩略图使用同一引擎，与编辑器显示一致。
  • 拖动滑块时，预览按显示器刷新率更新。
  • 搜索在后台运行，不会卡住界面。在 20,000 张照片的图库中，一次搜索约需 20 毫秒。
  • 导入大型图库时，内存占用不再持续增长。在 20,000 张照片的测试中，内存占用从 16.3 GB 降到 150 MB，耗时从约 5 分钟降到 39 秒。

修复​

  • 一次导入超过 1,024 个文件时不再丢失图片，未保存的评分也不再丢失。
  • macOS：神经网络去马赛克不再产生棋盘格图案。
  • macOS：高光恢复在部分图片尺寸下不再产生伪影。
  • macOS：安装版应用现在可以找到镜头校正数据。
  • 安装版应用现在可以根据镜头 ID 识别尼康镜头，镜头名称和镜头校正均正确。
  • Sony A7C II 的 ARW 文件及其线性 DNG 文件颜色和色阶正确。Canon EOS R6 Mark III 的 CR3 文件不再出现截断。
  • Windows：文件资源管理器、开始菜单和桌面快捷方式显示新的应用图标。
  • 在版本面板中，点击 + 会立即创建新版本。
  • 相册检查器支持鼠标滚轮滚动。
