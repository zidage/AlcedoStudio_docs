# 版本演进与升级指南

本文介绍 Alcedo Studio 的主要版本变化和升级注意事项。

---

## 升级核心注意事项

在跨大版本升级前，请重点了解以下架构与工作流变化：

| 变更项 | 涉及版本 | 升级与操作指引 |
| --- | --- | --- |
| **项目格式升级（不兼容 v0.2.x）** | **v0.3.0 起** | v0.3.0 全面重构了底层节点流水线与 DuckDB 项目格式。**无法直接打开 v0.2.9 及更早版本的项目**。建议保留旧版本软件以导出旧工程的成品，或在 v0.3.x 中新建项目重新导入源照片。 |
| **节点流水线与图层重构** | **v0.3.0 起** | 引入多节点串联、图层式蒙版组与 CAT02 创意白平衡。原有的旧式合并操作已平滑演进为更安全的 [选择性参数复制/粘贴](../getting-started/edit-history-and-versions.md)。 |
| **LUT 分发与编码重构** | **v0.3.1 起** | 官方胶片 LUT 包转为按需下载分发。升级后请进入 `设置 → LUT` 下载官方包；自定义 LUT 需在面板中正确指定输入/输出色彩空间编码。 |
| **导出预设** | **v0.3.3 起** | 导出预设取代了旧版仅包含文件名的预设，提供 Web、社交媒体和印刷等输出配置。网络分享预设默认关闭 GPS 位置写入。 |

---

查阅各版本的完整功能增补、性能优化与 Bug 修复细节，请点击侧栏的 **逐版更新记录**。
