UI 组件与源码映射索引

本索引梳理了 Alcedo Studio 各前端 QML 视图组件与其底层 C++ 业务逻辑服务之间的对应关系，为二次开发、自定义功能扩展与架构代码溯源提供参考导航。

前端视图组件与教程对应表​

应用主入口通过 main.cpp 加载 Alcedo.Main / Main.qml。前端组件树自顶向下分层如下：

功能层级核心 QML 视图组件底层业务与对应教程
窗口与项目宿主Main、AppDialogs、ProjectLaunchController、WelcomeDialog、TopToolbar项目加载、欢迎页与 界面总览
工作区容器WorkspaceHost、LibraryWorkspace、EditorWorkspace、EditorWorkspaceNavigation视图切换与 第一次编辑
集合与照片导入CollectionsPanel、FolderImportConfirmDialog、ImportProgressOverlay文件扫描与 图库管理
图库检查器InspectorPanel、AlbumInspectorPanel、ImageInspectorPanel、AlbumSectionView多维筛选与 图库管理
RAW 输入与几何构图EditorRawDecodePanel、LensCatalogPicker、EditorGeometryPanel解码与 输入与几何
工作区工具轨EditorWorkspaceRail、EditorAdjustmentStack、EditorAdjustmentHeader抽屉路由与 界面总览
调色节点与局部蒙版EditorNodesPanel、EditorMaskGroupsPanel、EditorNodeMaskDrawer、EditorMasksContextPanel拓扑流与 节点与蒙版
基础影调与创意外观EditorTonePanel、EditorLookPanel、EditorWhiteBalanceSection调色计算与 影调与色彩
3D LUT 胶片库EditorLutBrowserPanel、EditorLutControlPanel、LutSettingsPanel胶片管理与 LUT 库
显示变换与后期效果EditorDisplayTransformPanel、EditorPostProcessPanel、EditorScopePanelACES/OpenDRT 与 显示与后期
提交历史与版本分支EditorHistoryTransactionsPanel、EditorVersionsPanel、AdjustmentTransferDialogDAG 提交与 历史与版本
A/B 视觉对比EditorComparisonPanel、EditorComparisonView、EditorComparisonCanvas双缓存对比与 A/B 对比
批处理导出ExportInspectorPanel、ExportPresetPicker、ExportNamingEditor渲染队列与 导出工作流
AI 识别与全局搜索GlobalSearchDialog、SemanticGenerationSettingsPanel向量搜索与 AI 概览
系统首选项与任务SettingDialog、CacheSettingsPanel、KeyboardSettingsPanel、BackgroundTaskBar偏好设置与 系统设置

前端 QML 源码位于主仓库的 alcedo_studio/src/ui/alcedo_main/qml 目录下。

核心 C++ 服务与算法实现位置​

  • 导出预设构建与格式渲染：alcedo_studio/src/album_backend/export_recipe_builder.cpp
  • CLI 命令与 Schema 注册：alcedo_studio/src/alcedo_cli/cli_commands.cpp
  • 智能体协同控制与会话管理：alcedo_studio/src/automation/commands/control_commands.cpp
  • 节点流水线与场景色彩管理：alcedo_studio/src/gpu_pipeline/
  • DuckDB 资产管理与版本存储：alcedo_studio/src/album_backend/
