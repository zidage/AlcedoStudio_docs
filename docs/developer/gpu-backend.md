# GPU 后端与验证边界

v0.3.3 在 Windows 使用 CUDA / OpenCL，在 Apple Silicon macOS 使用 Metal，编辑器通过 Qt RHI 呈现。源码目录包括 `src/cuda`、`src/opencl`、`src/metal` 与 `src/ui/editor_rhi`。

## 选择与生效

在 Settings → Acceleration 选择图像处理后端，修改后自行重启应用。AI 模型推理有独立的运行时设置，不能把 AI 模型是否已激活当作图像 GPU 后端状态。

当前教程不再提供已移除的实验 WebGPU 处理路线。安装与平台要求见[安装说明](../getting-started/installation.md)。

## 验证同一张照片

比较后端时，固定源文件、版本、去马赛克、高光重建、镜头、几何、LUT 编码和显示变换；同时记录软件提交、Release / Debug、驱动、设备与输出尺寸。比较相同区域和相同输出格式，并区分：

- 首次打开与已缓存后的交互。
- FIT 预览、接近 100% 的细节与完整尺寸导出。
- 渲染完成时间与用户看到画面的时间。
- 图像差异、资源占用与操作延迟。

不要为了隐藏问题而改用更低质量或其他后端，再把结果算作原路径通过。

## 排查顺序

1. 检查后端是否可用、设置是否已在重启后生效。
2. 记录发生问题的照片、当前 Version 与具体操作。
3. 核对是预览、缩略图还是导出失败，保存原始错误。
4. 使用与报告相同的 Release 二进制复现；源码阅读不能代替这个步骤。

v0.3.0、v0.3.1、v0.3.2、v0.3.3 的性能与修复说明见[版本记录](../releases/upgrade-guide.md)。历史基准是特定测试的结果，不是当前设备的速度保证。本次教程截图验证为 Windows 单机操作，不是跨 GPU / 平台一致性测试。
