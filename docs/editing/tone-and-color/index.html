影调、曲线与色彩

先在节点（Nodes）或图层（Mask Groups）选中目标调色节点（Color Grade）。色调（Tone）、外观（Look）和 LUT 都随这个节点变化，右侧标题是判断编辑对象的依据。

色调（Tone）：从整体亮度到局部明暗​

Windows Release v0.3.3 实机：影调调整。

建议依次观察曝光 → 对比度 → 明暗部 → 黑白端点 → 曲线，不必每项都改。

控件用法
曝光（Exposure）建立整体亮度；同时看高光是否还有余量
对比度（Contrast）围绕中灰调整明度。v0.3.0 起新图默认 +15，保持中灰与色相
高光（Highlights） / 阴影（Shadows）调整明部与暗部，使用局部影调处理；放大检查强调整的边缘
白色色阶（Whites） / 黑色色阶（Blacks）整理亮端与暗端，避免只看缩略图把端点压死或推满
色调曲线（Tone Curve）精细改变明暗关系

曲线左键增加 / 拖动点，右键点删除，双击重置。滑块也支持双击恢复默认值。放开一次调整后查看历史（History），需要试另一方向时先建版本（Version）。

两种白平衡的区别​

Windows Release v0.3.3 实机：节点创意白平衡与色彩控件。

  • RAW 解码（RAW Decode）白平衡：修正拍摄输入，以相机数据为起点，作用于整张 RAW。
  • 外观（Look）白平衡：在调色空间中进行 CAT02 色适应，默认不改变颜色，不读取相机白平衡数据；可为节点或其蒙版范围加入创意冷暖，也适用于 JPEG 等位图。

例如先用 RAW 白平衡让中性物体正常，再在“主体”节点中稍微加暖。不要把外观（Look）中的色温数值直接当成相机白平衡的实测值复制；两处即使使用相同的开尔文（K）数值，也可能有不同外观。

饱和度与选择性色彩​

在外观（Look）的颜色（Color）区调整饱和度（Saturation） / 自然饱和度（Vibrance）。需要单独改变某一色相时，使用选择性色彩（Selective Color）：

  1. 选择目标色相，查看目标色相（Target Hue）。
  2. 调整色相偏移（Hue Shift）、明度（Lightness）或彩度（Chroma）。
  3. 用色相平滑度（Hue Smoothness）检查相邻色相过渡。
  4. 检查肤色、天空渐层与高饱和边缘，必要时缩小调整。

v0.2.5 对选择性色彩与色度处理进行了升级，旧版截图或数值配方不宜作为固定视觉结果。

色轮：阴影（Lift）、中间调（Gamma）与高光（Gain）​

这三个控件在中文界面仍显示 Lift、Gamma、Gain；这里的“阴影、中间调、高光”说明各自主要影响的范围。

色轮（Color Wheels）分别调整阴影、中间调、高光的颜色与主值。先做小幅颜色偏移，再用主控（Master）检查亮度影响；重置色轮（Reset wheels）可整体重置。

v0.3.1 更正 Gamma 色轮及其主滑块方向，并使 Gain 主滑块生效。升级前使用过这些控件的照片可能改变外观，请检查旧版本后再导出。

建议练习​

用同一张照片做两个版本：一个只改色调（Tone），一个在相同影调基础上改变外观（Look）。用对比模式看色彩是否改善主体，再决定是否加入 LUT 与后期效果。这些是练习顺序，不是每张照片必须使用的配方。
