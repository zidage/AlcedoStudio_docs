输入解码、色彩配置与几何构图

在进入调色之前，建立纯净准确的物理输入与严谨的构图是获得高品质成片的前提。Alcedo Studio 的图像流水线将 RAW 解码 / 位图输入色彩 与 几何构图 作为整张画面的全局基准。

RAW 照片：传感器级白平衡与去马赛克​

数码相机的 RAW 文件并非直接可见的 RGB 图像，而是传感器滤镜阵列（Color Filter Array, CFA）捕获的单通道感光强弱数据。

RAW 解码控制台：相机白平衡与镜头光学校准

1. 相机白平衡（Camera White Balance）​

  • 物理起点（As Shot）：软件默认读取机身记录的色温（Kelvin）与色彩偏向（Tint），直接作用于传感器的三原色增益比。
  • 与创意外观白平衡的区别：RAW 白平衡决定了画面进入场景线性工作流时的物理中性基准；后期的冷暖氛围烘托建议留给 外观（Look）面板 中的 CAT02 白平衡处理。

2. 去马赛克算法（Demosaicing Method）​

去马赛克决定了从单色马赛克阵列重构全彩三通道像素的锐度与纯净度：

  • RCD 算法（Ratio-based Corrected Demosaicing）：Bayer 传感器的默认算法。对高频边缘几何结构有极佳的保真度，能大幅抑制摩尔纹与拉链伪影。
  • 神经网络去马赛克（Neural Engine）：基于 GPU 硬件加速的深度学习去马赛克引擎。原生支持 Bayer 与 Fujifilm X-Trans 传感器。神经网络模型利用深层纹理先验知识重构微小细节，在控制噪点的同时杜绝伪色。
  • X-Trans 优化：针对富士独特的 6×6 滤镜阵列，系统默认调用专门训练的神经网络推理分支，消除传统插值带来的油画感与边缘杂色。

3. 高光重建（Highlight Reconstruction）​

当风光或逆光摄影中某一颜色通道发生物理过曝（如天空太阳边缘红绿通道溢出、蓝通道未满）时，常规插值会呈现难看的洋红或青色色块。勾选 启用高光重建 后，算法会利用未溢出通道的梯度信息智能推测高光亮度与色彩过渡，恢复自然的高光滚降。

4. 镜头光学校正（Lens Calibration）​

Alcedo Studio 深度集成了 Lensfun 镜头数据库：

  • 全自动识别：根据照片 EXIF 自动匹配相机卡口与具体镜头型号。
  • 综合校准：自动消除广角镜头的桶形畸变、长焦镜头的枕形畸变、边角失光（暗角）以及横向色差（紫边/绿边）。
  • 手动覆盖：老镜头或转接镜头如果未写入完整元数据，可点击选择器按品牌手动挑选镜头型号。

位图输入色彩空间（Raster Color Management）​

Alcedo Studio 支持导入 JPEG、TIFF、PNG 以及 OpenEXR。打开非 RAW 照片时，右侧会自动呈现 输入色彩（Input Color） / 输入配置文件（Input Profile）：

非 RAW 图像的色彩空间自动匹配与解析

  • 自动元数据检测（Auto metadata）：默认选项。引擎自动解析位图内嵌的 ICC 配置文件、PNG 色度块或 OpenEXR 线性原色。
  • 转换至场景线性流：无论是 sRGB、Display P3、Adobe RGB 还是 Rec.2020，系统都会将其精确逆向映射到 ACES 场景线性空间，让位图同样享受到节点调色与 ACES/OpenDRT 显示变换的强大能力。
  • HDR 位图支持：针对包含 PQ / HLG 曲线的 10 位以上 HEIF/TIFF 或 16/32 位半浮点 OpenEXR，系统会自动标记为 HDR 输入并保留高动态范围数据。

几何构图：智能裁剪与无缝旋转​

在构图环节，任何裁切与旋转都会作为不可逆画面的基础，后续所有的局部调色与显示输出均以此构图为边界。

利用网格与智能边界锁定进行构图

  1. 构图宽高比（Aspect Ratio）：
    • 包含标准画幅比例：原始（Original）、1:1、4:5（社交平台竖图）、16:9、3:2 等。
    • 勾选锁定比例后，拖动裁剪框角点将严格维持几何长宽比；点击自定义比例可按需设定特殊的画幅。
  2. 交互裁剪手柄：
    • 画布上提供三等分参考辅助线（Rule of Thirds）。
    • 直接在画面中拖拽四角或边框改变构图，也可以在右侧面板通过精确像素数值调整。
  3. 水平校准与旋转（Rotation）：
    • 拖动旋转滑块校准倾斜的地平线。
    • 智能边界包络算法：Alcedo Studio 在旋转画面时，裁剪矩形会自动内缩并保持在原始传感器的有效感光像素区域内，绝不产生旋转黑边或虚假填充像素。
  4. 重置与历史：
    • 点击 重置裁剪和旋转（Reset crop and rotation） 即可恢复满幅画面。

构建好干净的输入基准与画面比例后，请继续阅读 调色节点、图层与局部蒙版，进入多层次色彩塑造！
