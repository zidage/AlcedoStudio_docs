节点、蒙版组与局部调整

v0.3.0 起，一张照片可以串联多个调色节点。先明确正在编辑的节点，再调参数，避免把局部修改放到错误位置。

认识处理顺序​

显影节点（Develop）→ 调色节点 1（Color Grade 1）→ 调色节点 2（Color Grade 2）→ … → 显示变换（Display Transform）→ 后期处理（Post Processing）

显影节点（Develop）处理输入；每个调色节点（Color Grade）拥有色调（Tone）、外观（Look）、LUT 与自己的蒙版；显示变换（Display Transform）和后期处理（Post Processing）处理整张图。几何（Geometry）同样属于整张图的设置。

节点画布中的默认名称可能仍显示 Develop、ColorGrade、DRT；上面的中文用于说明其作用。DRT 是显示变换节点，ColorGrade 是可重命名的调色节点。

在节点（Nodes）中建立调色链​

Windows Release v0.3.3 实机：包含两个调色节点与径向蒙版的处理链。

  1. 打开左侧 节点（Nodes），确认显影节点（Develop）到显示变换（Display Transform）的连接。
  2. 使用 添加色彩分级（Add Color Grade） 新增调色节点，按用途重命名，例如“基础”“天空”“主体”。
  3. 使用节点端口连接处理顺序，完成从输入到输出的链。若界面提示连接尚未完成，先完成连接，再继续其他操作。
  4. 点选调色节点，查看右侧标题，确认色调（Tone）、外观（Look）与 LUT 正在编辑该节点。
  5. 通过适合（Fit）查看全图；需要删除时选中可删除的调色节点并使用删除操作。受锁定保护的节点不能直接删除。

节点图的增加、删除、连接及参数都进入历史与版本。分支试验前可先创建版本（Version）。

用图层（Mask Groups）管理图层顺序​

打开 图层（Mask Groups），每个调色节点作为一层显示，附带蒙版缩略图。新增组相当于添加一个独立调色层。拖动层调整顺序；调色顺序会影响结果，因此移动后应对比画面。

第一个调色节点默认锁定，含有 Alcedo 的默认调整。在这个节点上画蒙版，也会把默认调整限制到蒙版范围。首次做局部修改时，通常先添加新层更易理解。

设置（Settings） → 默认行为（Default Behavior） 可设置在锁定节点上添加蒙版时：每次询问、先建新层再绘制，或直接画在当前节点。这个偏好不影响你自己添加的未锁定层。

绘制径向蒙版：提亮主体​

Windows Release v0.3.3 实机：径向蒙版、图层列表与控制柄。

  1. 新建名为“主体”的调色层并选中。
  2. 选择径向蒙版工具，在照片上拖出椭圆。
  3. 在上下文 蒙版（Mask） 页调整名称、已启用（Enabled）、反相（Invert）、不透明度（Opacity）。
  4. 用画面控制柄或面板调整位置、水平 / 垂直半径、旋转（Rotation）、内羽化（Inner feather） / 外羽化（Outer feather）。
  5. 回到色调（Tone），适量提高曝光，检查过渡边缘。禁用蒙版或节点相关效果以核对作用范围。

位置控制区支持方向键微调，Shift 加大步长。

绘制渐变蒙版：压暗天空​

  1. 新建“天空”层，选择渐变蒙版工具。
  2. 在照片上拖出渐变，旋转使其贴合地平线。
  3. 调整 过渡宽度（Transition width） 控制过渡，用反相（Invert）改变方向。
  4. 在该节点降低曝光或高光，检查地平线附近是否出现明显分界。

蒙版不是全局裁剪。裁剪应在几何（Geometry）调整；蒙版决定当前节点的效果分布。v0.3.3 的常规发布预设未启用画笔蒙版，因此本教程只覆盖可用的径向与渐变工具。
