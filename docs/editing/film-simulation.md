# 胶片模拟：胶片印片、扫描与反转片

Alcedo Studio 的“胶片印片”根据胶片的光谱、特性曲线等数据，模拟场景在胶片上的曝光，再生成印片、负片扫描或反转片效果

本页对应 Alcedo Studio v0.3.5 的界面。胶片印片所需的资料随安装包提供；有关胶片 LUT 和自定义 LUT，请参阅 [3D LUT 库](./lut-library.md)

## 开始使用

1. 在图库中打开一张照片，进入编辑器
2. 在右侧打开 **显示变换**，将 **方法** 设为 **胶片印片**
3. 选择 **负片** 或 **反转片**，然后在 **胶片** 中选择片种
4. 选择负片时，在 **印片** 中选择相纸、电影拷贝片或 **负片扫描**；选择反转片后，画面按看片台观看效果显示
5. 展开 **风格** 和 **印片设置**，按照片调整画幅、颗粒、光晕和场景光

点击胶片或印片卡片可展开列表。负片和印片材料列表支持名称搜索和品牌筛选；选好后再次点击卡片可收起列表

可选片种包括 Kodak Portra、Vision3、Fujifilm Pro、Eterna、Velvia 和 Provia 等。印片材料包括相纸、电影拷贝片、展示材料和负片扫描

## 选择输出方式

| 选择 | 显示效果 | 输出 |
| --- | --- | --- |
| **负片 → 相纸或展示材料** | 模拟负片印放后的照片 | Rec.709 SDR |
| **负片 → 电影拷贝片** | 模拟电影拷贝片的放映效果 | Rec.709 SDR |
| **负片 → 负片扫描** | 模拟扫描负片并反相，再由 OpenDRT 显示 | SDR 或 HDR，取决于编码设置 |
| **反转片** | 模拟在看片台上观看幻灯片 | Rec.709 SDR |

选择负片扫描时，面板会显示 **负片扫描**、**扫描仪**、**OpenDRT** 和 **颜色与编码** 设置。其他输出方式使用各自的固定 SDR 输出

## 风格

**风格** 默认展开，包含以下控制：

- **画幅**：选择 16 mm、35 mm 或 70 mm，设置模拟胶片的画幅。同一画面使用较小画幅时，颗粒、光扩散和光晕在画面中的视觉尺寸更大
- **胶片颗粒**：调整颗粒强度，范围为 0%–200%；100% 对应所选胶片资料中的颗粒度
- **光晕**：调整强光周围的红色光晕；1 为标准强度

从其他方法切换到胶片印片时，若颗粒强度为 0，软件会将其设为 100%；已有的非零强度会保留。切换到其他显示变换方法时，颗粒强度会设为 0

## 印片设置

展开 **印片设置** 可调整：

- **场景光**：选择胶片曝光时的光线，包括参考、日光、钨丝灯、荧光灯、LED、钠灯及街道或室内光线。更换场景光会改变胶片对画面颜色的响应
- **按拍摄参数**：当 RAW 白平衡可用时，场景光列表会提供此选项，并使用 RAW 白平衡的色温。缺少 RAW 白平衡时，界面使用 **参考**，即胶片的平衡光
- **光扩散**：调整胶片乳剂内光线扩散的程度；1 对应胶片资料中的锐度，数值越大画面越柔和
- **放大机眩光**：调整印片时放大机镜头的杂散光。数值增大时，印片高光会变灰。负片扫描时此项隐藏
- **放大镜眩光**：选择反转片时显示，调整看片台放大镜的杂散光；数值增大时，暗部会变亮

## 负片扫描

选择 **负片 → 印片 → 负片扫描** 后，展开 **负片扫描** 可调整反相效果：

- **自动色彩**：选择 **关**、**中性**、**暖调** 或 **冷调**。选择“关”时保留场景光和胶片带来的偏色；其他模式根据预扫描调整偏色
- **自动色彩强度**：调整自动色彩校正的程度
- **自动密度**：调整预扫描的平均亮度向灰色基准靠拢的程度。自动色彩设为“关”时，自动色彩强度和自动密度均不起作用
- **扫描反差**、**扫描曝光**：调整反相后的反差和亮度
- **青**、**品红**、**黄**：微调正像的色彩
- **片基黑点**：调整片基映射到黑色的程度；1 将片基设为黑色

展开 **扫描仪** 可设置红、绿、蓝通道的中心波长、通道带宽和扫描仪光源。默认值对应理想扫描仪；修改这些参数会重新计算扫描所需的数据

展开 **OpenDRT** 可选择外观、色调映射和创意白点。在 **颜色与编码** 中设置编码色域、EOTF 和峰值亮度，以匹配 SDR 或 HDR 输出

## 设置如何保留

软件会记住通过界面使用的胶片、印片材料和场景光等胶片印片设置。之后在其他照片中选择胶片印片时，可以沿用这些设置

切换到胶片印片时，若默认调色节点的饱和度仍为软件默认值，软件会将它设为 0；其他饱和度数值会保留。照片的调整也可通过[编辑历史与版本](../getting-started/edit-history-and-versions.md)查看和复用
