3D LUT 库、胶片模拟与色彩空间编码

3D LUT（三维颜色查找表）是电影工业与高端摄影再现经典胶卷质感、影调分离以及胶片印片（Film Print）特性的核心利器。Alcedo Studio 拥有先进的色彩管理架构，彻底解决了传统软件加载 LUT 时常见的色彩截断与高光过曝难题。

官方胶片包与自定义 LUT 库管理​

为保持主安装包轻巧高效，Alcedo Studio 的官方胶片模拟库采用在线动态分发与签名校验机制：

设置中的官方胶片 LUT 包管理器

1. 下载与安装官方胶片模拟包​

  1. 进入顶部 设置（Settings） → LUT（LUTs） 面板。
  2. 在 官方 LUT 包（Official LUT Packages） 列表中，挑选经过专业色彩校准的经典胶片库（涵盖柯达 Kodak Portra、富士 Fujifilm Pro / Superia、CineStill 电影卷、Kodachrome 等知名胶片模拟）。
  3. 点击 下载（Download）。系统会在后台完成下载、数字签名完整性校验并自动解压部署。
  4. 部署完成后，状态标记为 已安装（Installed）。后续如有新版色彩优化，可在此直接一键点击更新或修复。

2. 导入第三方与自定义 .cube 文件​

如果你拥有调色师定制或商业购买的 .cube 查找表：

  1. 在 设置 → LUT 中查看当前的 LUT 库路径（LUT library path）。
  2. 点击 在文件资源管理器中打开（macOS 为 在访达中打开），将你的 .cube 文件或文件夹放入用户目录中。
  3. 点击 刷新（Refresh），自定义 LUT 将自动整理并呈现在浏览器的 用户（User） 分类下。

核心科学原理：输入与输出色彩空间编码​

在传统调色工具中，最容易发生的灾难性错误就是：将原本针对 Log 灰片或电视 Rec.709 制作的 LUT，直接盲目贴到物理线性的 RAW 照片上。结果往往是暗部死黑、高光如核爆般惨白。

Alcedo Studio 从底层色彩科学出发，为每个调色节点配备了严谨的 输入编码（Input Encoding） 与 输出编码（Output Encoding） 矩阵转换：

[ 场景线性色彩 (ACEScg) ]
           │
           ▼
[ 1. 输入色彩转换 ] ──▶ 将场景色彩转换为 LUT 所期望的色彩空间 (如 ARRI LogC3, Sony S-Log3, ACEScc)
           │
           ▼
[ 2. 3D LUT 三维变换 ] ──▶ 精确执行胶卷染料密度与色度映射
           │
           ▼
[ 3. 输出色彩转换 ] ──▶ 将 LUT 的输出还原回 ACES 场景色彩流水线
           │
           ▼
[ 后续调色与显示变换 ]

在调色面板中设置精确的输入与输出色彩编码

常见编码配置指南​

  • 官方胶片模拟包：专为 Alcedo Studio 场景线性流程量身定制，默认采用 ACEScc 输入与输出，加载即可获得完美画质，无需手动修改。
  • 电影机 Log LUT（如 ARRI LogC3、Sony S-Log3、Canon Log 2）：
    • 输入编码（Input）：选择对应的相机 Log 曲线（如 ARRI LogC3）。
    • 输出编码（Output）：通常选择 Rec.709 或 ACEScc。
  • 通用网络 / 社交平台预设 LUT：
    • 如果 LUT 说明要求“在普通图片上使用”，通常其输入和输出编码均应设定为 sRGB 或 Rec.709。
  • 为此 LUT 记住该设置（Remember for this LUT）： 勾选此项后，系统会在本地数据库中牢牢记住该 LUT 专用的输入/输出色彩配对。下次再次调用该 LUT 时，自动装载正确的色彩空间，彻底免除重复配置的烦恼。
强度不能掩盖编码错误

如果加载 LUT 后画面反差极度畸形，请先核对输入/输出编码，而不是简单地将强度滑块拉到 10% 来掩盖色彩截断。正确的编码能确保 LUT 在 100% 满强度下依然保留平滑的高光与纯净的暗部。

浏览、应用与强度混合​

进入编辑器，在左侧工具轨打开 LUT（LUTs） 抽屉：

可视化 LUT 浏览器：支持分类搜索、收藏与缩略图预览

  1. 精准检索：
    • 可按类别（Category：黑白、彩色负片、反转片、电影卷）、来源（Source）或品牌（Brand）进行筛选。
    • 在搜索框输入关键词（如“Portra 400”、“5207”）快速定位。
    • 点击星标按钮将常用 LUT 加入收藏。
  2. 挂载与应用：
    • 确保当前激活了正确的调色节点，在网格或列表中单击某个 LUT，视口画面将即刻呈现色彩质感；再次点击已选中项可安全卸载。
  3. 混合强度（Strength）：
    • 在右侧 LUT 面板中拖动 强度 滑块（0%–100%）。底层引擎会在未施加 LUT 的输入态与 100% 变换态之间进行高精度的线性插值，适合按个人喜好降低胶片浓烈度，获得轻盈通透的胶卷氛围。

配置好胶片模拟后，请继续阅读 显示变换、HDR 与后期质感，了解如何将场景线性画面准确呈现在显示器或电视上！
