界面总览

本页将介绍软件的主要界面与操作入口。

启动界面​

启动后首先进入启动界面。这里可以选择界面语言（目前有中文和英文两种）与 GPU 加速后端，并加载、创建项目，或从“Recent Projects”中直接打开最近的项目。点击“Create Project”会进入新建项目页，填写项目名称与存储位置后即可创建。

相册主界面​

打开项目后进入相册主界面，整体为三栏布局：

  • 左侧“LOCAL FOLDERS”：集合与文件夹列表，顶部“Search”标签打开全局搜索（见 AI 搜索与模糊搜索），底部“Import”按钮导入图像，“New collection”可新建集合，选中非根文件夹后可“Delete collection”删除。
  • 中间浏览区：以网格或列表显示缩略图，可用上方滑块或 Ctrl/Command + 滚轮缩放，双击图像进入编辑界面，右键打开上下文菜单（评分、Details、复制 / 粘贴调整、删除、加入其他集合等）。
  • 右侧检查器：显示“LIBRARY OVERVIEW”统计与筛选入口，包括按拍摄日期、相机型号、标签、评分、镜头等维度筛选；当存在活动搜索时，会出现“SEARCH FILTER”卡片显示当前查询并可清除。

编辑界面​

双击相册中的图像后进入编辑界面，这里是进行图像调整的主要界面。左侧栏可在 Edit History（当前 Version 的提交图）与 Versions（命名分支列表）之间切换；右侧是参数调整面板；中间是图像预览区域。面板用法见 编辑历史与版本（界面）。

导出​

选中图像后点击“Export”打开导出对话框，可选择目标目录、导出格式、分辨率、位深等参数，右侧显示导出队列及其状态。完成编辑后关闭编辑器面板回到相册页面，所有改动都会被自动保存。

设置与 AI​

点击工具栏 Settings（设置） 打开设置。与 AI 相关的设置分为两条路径：Local Content Recognition（本地内容识别） 用于下载、激活本地视觉模型和配置导入时的标签生成偏好；Advanced Content Analysis（高级内容分析） 用于创建 API 供应商配置、选择模型，并配置描述、评分与评分理由的生成方式。完整入口见 AI 功能概览 和 API 供应商配置。

相册左侧工具区还提供 Advanced Content Analysis（高级内容分析） 入口。打开项目并选中一张或多张照片后，点击该入口即可对当前选择运行 API 分析；没有选择照片时入口会保持不可用。
