编辑历史与版本（界面）

编辑器左侧栏提供两个面板：Versions 与 Edit History。它们面向同一张照片上的同一套编辑记录，只是一个管「有哪些命名分支」，一个管「当前分支上发生了哪些提交」。

说明： v0.2.8 之前的项目文件不受当前版本支持。请用当时的软件打开旧项目，或新建项目后重新导入。

Versions​

Versions 列出这张照片上的命名分支。每个条目显示名称，以及它当前指向的提交（或图像根）。

  • 点选一个 Version，就会改为使用它（若有未写入项目库的编辑，会先保存）。
  • Branch from current：从当前 Version 的最新提交再建一个分支。
  • Fork from root：从导入后的基准（尚未叠任何用户编辑）再建一个分支。
  • 可以重命名；非当前 Version 在仍至少保留一个 Version 时可以删除。

当前正在使用的 Version 用描边标出。编辑始终绑定在某个 Version 上。

Edit History​

Edit History 显示当前正在使用的 Version 上的提交图，并提供撤销与重做。

松开滑块时，当前这次调整会记成一条提交。撤销、重做是在这条图上移动，而不是改原始 RAW。

工具栏上还可以把别的照片上的调整拿过来用，见下一节。

从其他照片带入调整：粘贴与合并​

先在一张照片上复制调整，再打开目标照片。剪贴板里装的是「那一套参数」，不是整张图。接下来可以选 Paste 或 Merge，用途不同。

Paste（粘贴）​

适合：想在目标照片上另起一套完整的处理，并和原来的版本分开保存。

例如你在 A 上调好了曝光、白平衡和胶片 LUT，希望 B 也从这个配方开始试，同时保留 B 上已经做过的另一条分支——用 Paste。结果会在 B 上新建一个 Version，并改为使用它；B 原先的 Version 还在，只是不再是当前正在使用的。

Paste 不会在旧 Version 上打补丁，而是开一条新分支来承载传入的调整。

Merge（合并）​

适合：目标照片上已经有你想保留的修改，同时又想把另一张照片上的部分效果合进来。

例如你已经在 B 上裁好构图、调好曝光，又想沿用 A 上的色彩与 LUT；两边都动过的参数，希望自己决定留哪边——用 Merge。结果仍留在当前正在使用的 Version 上，不会为了这次操作再开一个新 Version。

若两边改过同一项参数，会先打开预览对话框，逐项选择保留当前、采用传入，或给出最终值。确认后写入一条合并提交；取消则当前 Version 不变。

怎么选​

你想做什么用哪个
把另一张的整套调整当作新起点，并和旧版本并排保留Paste
在现有版本上继续工作，只把另一张上有用的部分合进来Merge

更细的存储与恢复行为见 编辑历史与版本（Mini-Git）。
