# 界面总览

v0.2.8 起，图库与编辑器共用一个窗口。v0.3.3 的使用顺序是欢迎页 → 图库 → 编辑器 → 图库中的导出检查器。

教程中的按钮、菜单、面板和参数使用“中文（English）”对照，中文名称与 v0.3.3 的应用翻译一致。LUT、RAW、HDR 等缩写保留原名；界面仍保留英文的节点名和色轮会另外说明含义。

## 欢迎页：选择项目

![新建项目的名称和存储位置](/img/tutorial-v0.3.3/new-project.webp)

*Windows Release v0.3.3 实机：新建项目的名称和存储位置。*

点击 `新建项目…（New Project…）`，填写项目名称与父文件夹，创建 `.alcd` 项目；`打开项目…（Open Project…）` 用于打开已有项目。最近项目可显示照片封面、总数、已编辑数量和拍摄日期范围。先点选最近项目查看概览，再进入项目；仅预览不会保存该项目。

欢迎页提供语言选择。图像处理后端在 `设置（Settings） → 加速（Acceleration）` 管理，修改后需重启。

## 顶部工具栏

从左到右，主要入口包括集合侧栏开关、`图库（Library） / 编辑（Editor）` 工作区切换、`文件（File）` 菜单和 `设置（Settings）`。`文件（File）` 提供 `加载项目（Load Project）`、`创建项目（Create Project）`、`保存项目（Save Project）`。右侧侧栏按钮在图库控制检查器，在编辑器控制调整面板。

后台任务位于顶部状态灯。点击可查看正在运行、完成或失败的任务；智能体控制期间，其会话固定显示在任务区。见[设置与后台任务](../settings/preferences.md)。

## 图库：左侧集合、中间照片、右侧检查器

![图库与相册检查器](/img/tutorial-v0.3.3/library.webp)

*Windows Release v0.3.3 实机：图库与相册检查器。*

- **左侧**：`搜索（Search）`、`高级内容分析（Advanced Content Analysis）`、`后台任务（Background Tasks）`；下方是集合列表、创建和删除集合，以及 `从文件夹导入（Import From Folder）` / `导入图像（Import Images）`。
- **中间**：缩略图浏览区与缩放控制。选择照片后可评分、复制与粘贴调整、加入集合；双击进入编辑器。
- **右侧**：`相册（Album） / 图像（Image） / 导出（Export）`。相册（Album）查看统计、筛选、排序与分组；图像（Image）查看当前照片信息与分析结果；导出（Export）管理导出参数与队列。

点击统计值是筛选，字段旁的动作是排序或分组。这三个操作不同，详见[图库管理](../library/import-and-organize.md)。

## 编辑器：先选节点，再调参数

![单窗口编辑器与影调面板](/img/tutorial-v0.3.3/editor-tone.webp)

*Windows Release v0.3.3 实机：单窗口编辑器与影调面板。*

左侧工具轨包含 `历史（History）`、`版本（Versions）`、`节点（Nodes）`、`图层（Mask Groups）`、`LUT（LUTs）` 和 `后台任务（Tasks）`。点击打开对应面板，再次点击可收起。中间是照片，底部可展开胶片带切换照片；胶片带沿用图库集合和筛选结果。

中文界面的图层入口显示“图层”，打开后的面板标题是“图层（蒙版组）”，对应英文 Mask Groups。

右侧上方是直方图 / 波形和照片信息，调整区按以下顺序排列：

1. **RAW 解码（RAW Decode）**：输入与相机白平衡；位图会显示输入色彩（Input Color）。
2. **几何（Geometry）**：整张图的裁剪与旋转。
3. **色调（Tone）**：所选调色节点的曝光、明暗和曲线。
4. **外观（Look）**：节点白平衡、饱和度、选择性色彩和色轮。
5. **LUT**：该节点的 LUT、强度和编码。
6. **显示变换（Display Transform）**：整张图的显示变换与输出编码。
7. **后期处理（Post Processing）**：整张图的柔光、清晰度、锐化、颗粒和光晕。

`蒙版（Mask）` 与 `对比（Compare）` 为上下文页面，在绘制 / 编辑蒙版或打开对比时显示。多个调色节点各有自己的色调（Tone）、外观（Look）、LUT 和蒙版，右侧标题说明正在修改哪个节点。

## 返回图库与导出

通过顶部 `图库（Library）` 返回图库，无需关闭一个独立编辑窗口。选中照片，点击 `加入队列（Add to Queue）`，在右侧 `导出（Export）` 配置并开始导出。编辑历史保存与图像导出是不同步骤；看见编辑器效果不代表已生成文件。继续[第一次编辑](./first-edit.md)。
