# 界面总览

本页将介绍软件的几个主页面。

## 项目管理页面

![项目管理](/img/interface/project_mgmt.png)
这里用户可以选择语言（目前有中文和英文两种），以及创建或打开项目。

## 相册页面

![相册页面](/img/interface/album.png)
用户打开项目后进入相册页面，这里会显示项目中的所有图像。用户可以在这里进行图像的浏览和删除等操作。

## 编辑页面

![编辑页面](/img/interface/edit.png)
用户双击相册中的图像后进入编辑页面，这里是进行图像调整的主要界面。左侧是编辑历史，右侧是参数调整面板，中间是图像预览区域。用户可以在这里进行各种参数的调整，并实时预览效果。

## 导出页面

![导出页面](/img/interface/export.png)
用户完成编辑后可以进入导出页面，这里可以选择导出的格式、分辨率等参数。用户可以在右侧查看导出队列中的图像。
