# 界面总览

本页将介绍软件的主要界面与操作入口。

## 启动界面

![项目管理](/img/interface/project_mgmt.png)

启动后首先进入启动界面。这里可以选择界面语言（目前有中文和英文两种）与 GPU 加速后端，并加载、创建项目，或从“Recent Projects”中直接打开最近的项目。点击“Create Project”会进入新建项目页，填写项目名称与存储位置后即可创建。

## 相册主界面

![相册页面](/img/interface/album.png)

打开项目后进入相册主界面，整体为三栏布局：

- 左侧“LOCAL FOLDERS”：集合与文件夹列表，顶部“Search”标签打开全局搜索（见 [AI 搜索与模糊搜索](../ai/search.md)），底部“Import”按钮导入图像，“New collection”可新建集合，选中非根文件夹后可“Delete collection”删除。
- 中间浏览区：以网格或列表显示缩略图，可用上方滑块或 `Ctrl/Command` + 滚轮缩放，双击图像进入编辑界面，右键打开上下文菜单（评分、Details、复制 / 粘贴调整、删除、加入其他集合等）。
- 右侧检查器：显示“LIBRARY OVERVIEW”统计与筛选入口，包括按拍摄日期、相机型号、标签、评分、镜头等维度筛选；当存在活动搜索时，会出现“SEARCH FILTER”卡片显示当前查询并可清除。

## 编辑界面

![编辑页面](/img/interface/edit.png)

双击相册中的图像后进入编辑界面，这里是进行图像调整的主要界面。左侧是编辑历史，右侧是参数调整面板，中间是图像预览区域。用户可以在这里进行各种参数的调整，并实时预览效果。

## 导出

![导出页面](/img/interface/export.png)

选中图像后点击“Export”打开导出对话框，可选择目标目录、导出格式、分辨率、位深等参数，右侧显示导出队列及其状态。完成编辑后关闭编辑器面板回到相册页面，所有改动都会被自动保存。

## 设置与 AI

点击工具栏“Settings”打开设置，包含 Language、Theme and color、Cache 与 AI 四个分类。AI 分类用于下载、激活与管理 AI 模型，以及配置导入时的标签生成偏好，详见 [AI 功能概览](../ai/overview.md)。
