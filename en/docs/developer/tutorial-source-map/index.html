UI Components & C++ Source Map Reference

This reference index links Alcedo Studio’s QML presentation components to their underlying C++ business logic services, providing a clear map for customization, extensions, and code navigation.

Front-End QML Views to Architecture Mapping​

The application entry point main.cpp loads Alcedo.Main / Main.qml. The component tree branches as follows:

Functional TierPrimary QML ComponentsUnderlying Subsystem & Documentation
Window & Project ShellMain, AppDialogs, ProjectLaunchController, WelcomeDialog, TopToolbarCatalog load, welcome launcher & Interface Overview
Workspace RoutingWorkspaceHost, LibraryWorkspace, EditorWorkspace, EditorWorkspaceNavigationView transitions & Your First Edit
Collections & IngestionCollectionsPanel, FolderImportConfirmDialog, ImportProgressOverlayFolder scanning & Library Management
Library InspectorInspectorPanel, AlbumInspectorPanel, ImageInspectorPanel, AlbumSectionViewMulti-dimensional culling & Library Management
RAW Input & GeometryEditorRawDecodePanel, LensCatalogPicker, EditorGeometryPanelSensor decode & Input & Geometry
Tool Rails & DrawersEditorWorkspaceRail, EditorAdjustmentStack, EditorAdjustmentHeaderTool drawer routing & Interface Overview
Grading Nodes & MasksEditorNodesPanel, EditorMaskGroupsPanel, EditorNodeMaskDrawer, EditorMasksContextPanelDAG pipeline & Grading Nodes & Masks
Tone & Creative LookEditorTonePanel, EditorLookPanel, EditorWhiteBalanceSectionColor math & Tone, Curves & Color Grading
3D LUT Film LibraryEditorLutBrowserPanel, EditorLutControlPanel, LutSettingsPanelFilm packages & 3D LUT Library
Display & Post ProcessingEditorDisplayTransformPanel, EditorPostProcessPanel, EditorScopePanelACES/OpenDRT & Display Transform & Effects
History & Version BranchesEditorHistoryTransactionsPanel, EditorVersionsPanel, AdjustmentTransferDialogCommit DAG & Edit History & Versions
A/B ComparisonEditorComparisonPanel, EditorComparisonView, EditorComparisonCanvasDual-buffer viewport & A/B Comparison
Batch ExportExportInspectorPanel, ExportPresetPicker, ExportNamingEditorRender queue & Export Workflow
AI Vision & Global SearchGlobalSearchDialog, SemanticGenerationSettingsPanelVector search & AI Overview
Preferences & MonitoringSettingDialog, CacheSettingsPanel, KeyboardSettingsPanel, BackgroundTaskBarSystem preferences & Settings & Preferences

Front-end QML sources are located in alcedo_studio/src/ui/alcedo_main/qml.

Core C++ Services & Engine Source Locations​

  • Export Recipe Builder & Pipeline Delivery: alcedo_studio/src/album_backend/export_recipe_builder.cpp
  • CLI Commands & Schema Registration: alcedo_studio/src/alcedo_cli/cli_commands.cpp
  • Agent Session Control & Command Dispatch: alcedo_studio/src/automation/commands/control_commands.cpp
  • Node-Based Color Pipeline & ACES Encodings: alcedo_studio/src/gpu_pipeline/
  • DuckDB Sleeve Catalog & Version Branches: alcedo_studio/src/album_backend/
