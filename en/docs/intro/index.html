Alcedo Studio tutorials

These tutorials use v0.3.3 as their operating baseline and cover changes from v0.2.x through v0.3.3. Projects store photo references, edits and named versions; editing leaves the source photos unchanged.

Start here​

  1. Install the application.
  2. Find your way around the interface.
  3. Import, edit and export your first photo.

Follow the workflow​

StageTutorial
Import and selectFile types, collections, ratings, filters, sorting and grouping
Input and compositionRAW, raster input color, lens correction, crop and rotation
Local adjustmentsNodes, Mask Groups, radial and gradient masks
Tone and colorExposure, curves, two white balances, selective color and wheels

PreferencesSettings, cache, shortcuts, updates and tasks

Upgrading​

Read the upgrade guide first. v0.3.0 and later cannot open or automatically migrate projects from v0.2.9 or earlier. LUT distribution, crop behavior, color wheels and diffusion also changed.

The release archive retains complete feature, improvement, performance and fix notes for all fourteen versions, linked to current tutorials. See the source map for the production QML entry points and verification scope.
