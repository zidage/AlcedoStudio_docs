v0.2.x to v0.3.3: changes and upgrading

Current tutorials describe v0.3.3. Complete release notes below retain performance results and fixes as historical reports, not promises for your hardware.

Before upgrading​

ChangeAction
v0.3.0 cannot read v0.2.9 or earlier projectsKeep the old app/project; export there or reimport originals into a new project. No automatic migration
v0.3.0 removes MergeUse selective copy/paste, which creates a target Version
v0.3.1 stops bundling LUTsDownload official packages in Settings → LUTs and transfer custom resources
v0.3.1 changes crop and wheelsCheck rotated crops, Gamma and Gain in existing edits
v0.3.2 changes diffusion curveCheck halos near whites
v0.3.3 replaces filename presetsSave complete export presets again and check destination
v0.3.3 retains GPS by defaultDisable GPS for sharing, or choose Web / Social Media / Email
v0.3.3 RAW time fix affects new importsExisting Library records are not automatically corrected

Patch tags and builds​

The repository also retains v0.2.0-hotfix, v0.2.3b, v0.2.4-Release and v0.2.8-Preview. Reproduce those using their exact tags and commit differences; the main version notes are not an individual test report for every installer.

v0.2.9 builds 2014/2015 additionally record inspector export, signing, embedded localized notes and the Windows installer-only change. They are included in v0.2.9.

Verification​

The tutorials follow tagged production QML and relevant C++ validation. Windows Release screenshots and a limited CLI/GUI demonstration were checked; exports, remote AI, macOS and all GPU paths were not fully tested. See the source and screenshot map.
